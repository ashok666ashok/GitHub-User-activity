# GitHub-User-activity
a simple command line interface for github user activity
CLI fetches → displays GitHub user activity.

## Install

```bash
git clone https://github.com/ashok666ashok/GitHub-User-activity
cd <repo_dir>
npm install
npm link
```
##<ins>command</ins>
github-activity <username>
